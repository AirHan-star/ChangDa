## 1. Python 与 NumPy

Python 列表与 NumPy 数组不同：数组支持逐元素运算，`@` 表示矩阵乘法。

```python
import numpy as np
x = np.array([1.0, 2.0, 3.0])
print(x * 2)
A = np.array([[1, 2], [3, 4]])
B = np.array([[5], [6]])
print(A @ B)  # [[17], [39]]
```

矩阵相乘要求左矩阵列数等于右矩阵行数；(m,n) @ (n,p) 得到 (m,p)。

## 2. 前向传播（Forward Propagation）

单神经元：z = w·x + b，a = f(z)。Sigmoid 激活函数将输出映射到 (0,1)。

```python
import numpy as np
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x = np.array([1., 2.])
w = np.array([0.3, 0.5])
b = 0.1
z = np.dot(w, x) + b
print(z, sigmoid(z))  # 1.4, 约 0.802
```

## 3. 损失函数（Loss Function）

均方误差（Mean Squared Error, MSE）：L = (1/n) Σ(y_pred - y_true)²。

```python
y_true = np.array([1., 0., 1.])
y_pred = np.array([0.8, 0.3, 0.6])
loss = np.mean((y_pred - y_true) ** 2)
print(loss)  # 0.096666...
```

训练损失低不一定代表泛化能力好，需要验证集判断过拟合。

## 4. 梯度下降（Gradient Descent）

学习率（Learning Rate）控制每次参数更新的步长。更新规则：w ← w - lr * dw，b ← b - lr * db。

以下用 y_hat = wx+b 学习 y=2x。MSE 梯度为 dw=(2/n)Σx(y_hat-y)，db=(2/n)Σ(y_hat-y)。

```python
import numpy as np

x = np.array([1., 2., 3., 4.])
y = np.array([2., 4., 6., 8.])
w, b = 0., 0.
lr = 0.05
n = len(x)

for epoch in range(1000):
    y_pred = w * x + b
    loss = np.mean((y_pred - y) ** 2)
    dw = (2 / n) * np.sum(x * (y_pred - y))
    db = (2 / n) * np.sum(y_pred - y)
    w -= lr * dw
    b -= lr * db
    if epoch % 100 == 0:
        print(f"epoch={epoch}, loss={loss:.6f}, w={w:.4f}, b={b:.4f}")

print("最终参数", w, b)
```

观察损失是否下降、w 是否趋近 2、b 是否趋近 0。将学习率分别改为 0.001 和 0.5，观察收敛慢或发散的情况。
