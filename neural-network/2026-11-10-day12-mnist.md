## 二、分类基础

### 1. 回归与分类

- 回归：预测连续数值，例如 y = x1 + 2*x2。
- 分类：预测离散类别，例如判断一张手写图片属于数字 0–9 中的哪一类。

### 2. Logits、Softmax 与类别预测

- 分类模型最后一层输出每个类别的原始分数，称为 Logits；Logits 不是概率。
- Softmax 可将 Logits 转换为总和为 1 的类别概率。
- `argmax(dim=1)` 沿类别维度选出分数最大的类别索引。

### 3. CrossEntropyLoss

使用方式：

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, labels)
```

重要约定：

- 输入应为原始 Logits，不要在 CrossEntropyLoss 前手动 Softmax。
- 标签通常是类别整数索引，而不是 One-Hot 向量。
- PyTorch 的 CrossEntropyLoss 内部组合了 LogSoftmax 与 NLLLoss。

### 4. Accuracy

`Accuracy = 预测正确样本数 / 总样本数`。

实践中使用：

```python
predicted = outputs.argmax(dim=1)
accuracy = (predicted == labels).float().mean()
```

## 四、MNIST MLP 模型

模型结构：

```text
Input: 784
  ↓
Linear(784, 128)
  ↓
ReLU
  ↓
Linear(128, 10)
  ↓
Logits for classes 0–9
```

理解要点：

- 784：每张 28×28 图片展平后的输入特征数量。
- 128：隐藏层神经元数量，是模型超参数，不是图片尺寸或类别数量决定的。
- 10：输出类别数量，对应数字 0–9。
- 最后一层不加 Softmax，因为 CrossEntropyLoss 接收原始 Logits。

单 Batch 前向传播检查结果：

| 项目 | 形状 |
|---|---|
| images | (64, 1, 28, 28) |
| 展平后 | (64, 784) |
| outputs | (64, 10) |
| labels | (64,) |
