# 松岭余讯

一款用 Godot 4 和 GDScript 制作的第三人称 3D 离线生存原型。白天进林地采集物资，入夜守住气象站的大门。

## 在 Windows x64 试玩

下载并解压 [Windows 应用包](dist/PineRidgeRelay-Windows-x86_64.zip)，双击 `PineRidgeRelay.exe`。游戏资源已嵌入 EXE，可离线运行，无需安装 Godot。

| 按键 | 操作 |
| --- | --- |
| WASD、鼠标 | 移动和转动镜头 |
| Shift、空格 | 奔跑和跳跃 |
| E | 靠近木料或罐头拾取，靠近石矿开采，靠近补给箱存入物资 |
| Tab | 打开合成面板，查看配方并点击制作 |
| B | 打开背包，查看物资和工具，点击已有工具装备 |
| 1 / 2 / 3 | 木镐 / 石镐 / 石剑快捷键。材料足够时制作，已有时装备 |
| R | 白天靠近气象站大门加固，结算后重新开始 |
| 左键、Esc | 左键挥动已装备的工具。Esc 关闭面板或释放鼠标，单击画面重新捕获 |

### 一局怎么玩

1. **白天 1 分 45 秒。** 沿林间小路找金色木料和青色罐头。按 Tab 用 2 份木料制作木镐，再靠近带浅蓝矿脉的石矿。按 E 或持镐左键开采，每处产出 3 块石头。木镐需要敲击三次，石镐一次即可。
2. **天黑前加固。** 靠近气象站大门按 R，每次消耗 2 份木料、增加 32 点耐久，最多 3 次。补给箱会存入随身的全部木料和罐头，建议先留出制作和加固材料。补给任务仍需交付至少 3 份木料和 1 个罐头。
3. **夜晚 52 秒。** 大门关闭，感染者沿小路来袭，只攻击大门。可以提前回站内依靠加固撑过夜晚，也可以留在门外，在背包中装备石剑，朝向近处的感染者并左键攻击。矿石和感染者均有实体碰撞，林区边界由铁皮墙围住。
4. **撑到天亮获胜，大门耐久归零则失败。** 结算后按 R 或点击“重新开始”开启新一局。

木料和石矿只在白天原地补充，分别间隔 15 秒和 21 秒。每局白天最多出现 22 份木料和 8 处石矿，同时最多有 8 份木料和 3 处石矿。感染者同时最多 4 名，每晚累计最多 10 名。

## 在 Godot 中修改和导出

用 Godot **4.6.3** 导入本目录的 `project.godot`，按 **F5** 运行。主场景是 `scenes/main.tscn`。拾取、背包、配方和交付规则在 `scripts/supply_rules.gd`，昼夜和门耐久规则在 `scripts/survival_rules.gd`。

更新时在本目录修改工程。安装对应版本的 Godot 导出模板后，在编辑器中使用 **Windows Desktop** 预设导出。预设会生成包含游戏资源的 `dist/PineRidgeRelay.exe`。将新 EXE 与现有压缩包内的许可证文件一起打包，替换本目录 `dist/` 下的应用包。
