# 松岭余讯

用 Godot 4 和 GDScript 制作的第三人称 3D 离线单人生存游戏。撤离广播中断后，从松岭气象站出发，沿线追查最后收到的电报。

## 试玩

下载并解压 [Windows x64 应用包](dist/PineRidgeRelay-Windows-x86_64.zip)，双击 `PineRidgeRelay.exe`。游戏资源已嵌入，支持离线运行。

| 按键 | 操作 |
| --- | --- |
| WASD、鼠标、Shift、空格 | 移动、转动镜头、奔跑、跳跃 |
| E | 拾取、开采、搜刮箱子、查看线索或使用工作设施 |
| F | 靠近传送门打开目的地列表 |
| J | 阅读最近的剧情记录 |
| Tab、B | 查看合成配方、打开背包装备工具 |
| 左键 | 挥动工具。装备卡宾枪时长按连发 |
| R | 持枪换弹，未持枪时保存进度 |
| 按住右键 | 装备卡宾枪时进入越肩瞄准，松开恢复普通镜头 |
| 1、2、3 | 制作或装备木镐、石镐和石剑 |
| H | 消耗一罐罐头，最多回复 30 点生命 |
| F5 | 立即存档 |
| Esc | 关闭面板或释放鼠标 |

## 生存与主线

- 第一次进入游戏时，调查气象站内的通讯台。往后按左上角的目标与方位找线索。灰脊采石场、沉钟旧城、黄烟盆地依次开放。主线完成后仍能采集、制作和往返各区。
- 白天 3 分 30 秒，夜间 1 分 35 秒。感染者在刷新点附近徘徊。玩家进入约 8 米且视线畅通时开始追击，离刷新点约 17 米后放弃追击并返回。气象站入口昼夜可通行。
- 木料和矿脉散布在道路两侧，只在白天补充。三张外出地图的建筑均可进入，每栋会随机放置木箱或铁箱之一，箱型随存档固定。箱子搜空后按现实时间 10 分钟补货，关掉游戏也会计时。装备铁斧后靠近松树按左键或 E 砍树，砍完得 4 份木料，留下的树桩经过 5 分钟游戏世界时间再生。铁矿仅在灰脊采石场出现，硫磺仅在黄烟盆地出现，两者至少需要石镐。
- 在气象站内用 Tab 制作工作台。随后靠近工作台，用木料和石材制作熔炉。靠近熔炉可以制作生铁和游戏火药，再回工作台制作铁镐、铁斧及弹药。枪械图纸随旧城主线开放。
- 存档会记录位置、昼夜、进度、背包、制作设施和资源状态。倒下后可返回气象站，在次日清晨醒来并保留背包和主线进度。

## 断线公路

在任一传送门按 **F**，选「断线公路」即可进入独立挑战。入场获得临时卡宾枪，弹匣 20 发，后备弹药无限。按 **R** 主动换弹，打空后继续按住左键也会自动换弹。

首波在开局 3 秒后出现，此后每隔 15 秒从公路远端刷新一波，前面波次的存活感染者继续留场。选择强化或打开退出菜单时暂停计时。后续波次血量和数量逐步提高，公路普通感染者和头目的生命值为上一版的两倍。击杀获得经验，升级可选伤害、攻速、经验加成、扩容、换弹速度、护甲或急救，也可能抽到贯穿、第四发双倍伤害、击杀回弹、击杀回血或换弹后短时连射加速。第 **10、20、30** 波会出现大型重装感染者。第 30 波是最后一波，消灭所有剩余感染者后获胜。倒下会结束挑战，也可按 **Esc** 打开离场菜单。返回时恢复进入前的生存位置、生命和装备。公路局内进度、临时枪与强化随本局结束清除。

## 在 Godot 中修改和导出

用 Godot **4.6.3** 导入本目录的 `project.godot`，按 **F5** 运行。主场景为 `scenes/main.tscn`。分区与资源点配置在 `scripts/survival_region.gd`，主线在 `scripts/relay_story.gd`，背包和配方在 `scripts/supply_rules.gd`。

安装对应版本的 Godot 导出模板后，用 **Windows Desktop** 预设导出 `dist/PineRidgeRelay.exe`。将 EXE 与当前 ZIP 内的许可证一起打包，替换应用包。
