## 3. 已完成的实战与结果

1. 单神经元 NumPy 前向传播：运行成功。
2. NumPy 梯度下降与批量梯度：运行成功，核对过梯度与损失。
3. NumPy 训练循环 100 轮，损失由约 0.451667 降至约 0.046665。
4. PyTorch Autograd：对单神经元自动求导，梯度与手算一致。
5. PyTorch SGD：一次参数更新后损失从 0.81 降至约 0.0324。
6. MLP 前向传播：两层网络，输入形状 (2,2)，输出形状 (2,1)，参数总数 17。
7. MLP 训练：用合成关系 y = x1 + 2*x2 训练；在少量新样本上做了初步预测检查。
8. 数据集划分：100 个合成样本划分为 70/15/15，程序运行成功。
9. DataLoader 小实验：10 个样本、batch_size=4，输出三个 Batch，大小分别为 4、4、2。
10. DataLoader + MLP：100 个合成样本按 80/20 划分；训练 batch_size=16、验证 batch_size=16；完成 20 Epoch 训练。Train Loss：5.598103 → 0.053713；Val Loss：5.460529 → 0.033922。
11. Dropout 模式实验：训练模式输出随机置零并缩放；评估模式输出全 1；训练模式配合 no_grad 时仍有 Dropout 行为，但不记录梯度。
12. 完整训练/验证/测试实战：100 个合成样本按 70/15/15 划分，Batch Size 16，MLP 结构 2→4→1，Adam 学习率 0.01，30 Epoch。最终 Train Loss 0.040270，Validation Loss 0.035808，Test Loss 0.027175。
13. 分类基础练习：使用三个类别的 Logits，CrossEntropyLoss 和 argmax/Accuracy 计算成功；示例准确率 66.67%。
14. MNIST MLP 图像分类：训练/验证/测试数据为 55,000/5,000/10,000；模型 784→128→10；Adam 学习率 0.001，Batch Size 64，3 Epoch。Test Loss 0.10719，Test Accuracy 96.77%。
15. CNN 卷积运算实验：F.conv2d() 手动卷积得到预期 3×3 特征图。
16. Conv2d/Pooling 形状实验：输入 (64,1,28,28)，卷积后 (64,8,28,28)，池化后 (64,8,14,14)，展平后 (64,1568)。
17. MNIST CNN 实战：Conv2d(1,8,3,padding=1) → ReLU → MaxPool2d(2,2) → Flatten → Linear(1568,128) → ReLU → Linear(128,10)，Adam lr=0.001，Batch Size 64，3 Epoch。
    - Epoch 1：Train Loss 0.3313，Train Accuracy 90.43%，Validation Loss 0.1807，Validation Accuracy 94.40%。
    - Epoch 2：Train Loss 0.1374，Train Accuracy 95.93%，Validation Loss 0.1236，Validation Accuracy 96.02%。
    - Epoch 3：Train Loss 0.0940，Train Accuracy 97.13%，Validation Loss 0.1029，Validation Accuracy 96.64%。
    - Test Loss 约 0.088198，Test Accuracy 97.21%。
    - 与 MLP 测试准确率 96.77% 相比，本次 CNN 高 0.44 个百分点。

边界说明：目前 MNIST CNN 是基础模型，3 Epoch 的结果用于入门实验与初步比较。尚未完成系统参数量/计算量对比、特征图可视化、误分类分析、CNN 调参或论文复现。Matplotlib 可视化安装/运行状态尚未确认。
